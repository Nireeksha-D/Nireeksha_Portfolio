# Nireeksha D — Developer Portfolio

A modern, responsive software developer portfolio for Nireeksha D. The site presents full-stack experience, AI automation work, technical skills, projects, education, certifications, activities, and direct contact links in a premium dark interface.

## Technology

- React 19 and TypeScript
- TanStack Start and TanStack Router
- Tailwind CSS 4 with a custom CSS design system
- Lucide React and React Icons
- Netlify deployment adapter

## Local Development

```bash
pnpm install
pnpm dev
```

The local Vite server runs on port `3000` by default.

## Production

```bash
pnpm build
```

Netlify uses the configuration in `netlify.toml` and publishes the generated TanStack Start output.

## Content

The one-page portfolio is implemented in `src/components/portfolio.tsx`, with global visual styling and responsive behavior in `src/styles.css`. The downloadable resume is available at `public/Nireeksha-D-Resume.pdf`.
